成功案例

留學顧問數據調研——精準鎖定潛在客戶

客戶背景

一家成立5年的香港本地海外留學顧問公司，主要協助中學生申請英國、澳洲及加拿大的寄宿學校與大學。公司有約10名顧問，每年服務約200名學生，但近年面臨市場競爭加劇與客戶增長放緩的問題。

面臨挑戰

    市場上同類留學顧問公司數量在3年內增加了近40%，競爭白熱化。

  • 客戶過往依賴展會與學校講座獲取客源，但這些傳統渠道的轉換率持續下降。
  • 對目標客戶群的決策過程缺乏數據化理解：家長和學生在選擇留學顧問時最看重什麼？他們從哪裡獲取資訊？
  • 希望拓展新服務（如海外大學申請、學術補習），但不確定市場需求是否存在。

我們的解決方案

設計並執行了一項為期6週的市場調研項目：

✓ 向800名過去3年曾諮詢留學服務的家長發放問卷，回收有效樣本512份，深入了解他們的決策流程、資訊渠道與選擇顧問的關鍵因素。

✓ 與12位曾使用留學顧問服務的家長進行深度訪談，挖掘未滿足的需求與痛點。

✓ 分析網上論壇與社交媒體上有關留學顧問的討論內容，識別市場趨勢與競爭對手的優劣勢。

✓ 收集並整理英國、澳洲、加拿大三國的最新留學簽證政策與大學錄取數據，為客戶提供市場機會分析。

✓ 根據調研結果，為客戶提供具體建議：優化網站內容以匹配家長搜尋習慣、調整廣告投放渠道、以及優先拓展加拿大大學申請服務。

成果

客戶根據調研報告調整了市場策略，網站查詢量在3個月內增長了65%，展會以外的渠道（線上廣告與社交媒體）帶來的客戶比例從15%提升至40%。新推出的加拿大大學申請服務在首年內帶來額外120萬港元營收。客戶現正委託我們進行第二次調研，針對澳洲市場的擴張機會進行更深入的分析。

米芝蓮星級餐廳開業——從概念到落地的一站式服務

背景

一位曾在米芝蓮星級餐廳任職的日籍主廚，計劃在香港開設自己的第一家餐廳，主打現代懷石料理。他雖然擁有頂尖廚藝，但對香港餐飲市場的運營實務完全陌生。

客戶需要

  • 尋找合適的店舖位置
  • 申請各類餐飲牌照
  • 建立本地食材供應鏈
  • 人手招聘
  • 定價策略缺乏經驗
  • 預算有限，需要在控制成本的同時確保開業品質

我們的解決方案

✓ 協助客戶進行選址分析，評估超過10個潛在店舖的人流、租金與競爭環境。

✓ 代辦所有餐飲牌照申請，包括食環署牌照、酒牌等。

✓ 建立本地食材供應鏈，協助客戶在品質與成本之間取得平衡。

✓ 制定開業營銷計劃，包括試菜活動與媒體公關策略。

✓ 在IG、Facebook、小紅書建立網上話題，引導輿論，引起市場關注。

成果

餐廳在6個月內順利開業，開業首月即獲得米芝蓮指南推薦，營運首年毛利率達到38%，成為區內熱門預約餐廳。客戶現正籌備第二間分店。

零售品牌——5店老闆的擴張抉擇

背景

一家擁有40年歷史的香港零售品牌，全盛時期在港擁有10間門店，近年因電商衝擊與消費習慣改變，生意大幅下滑。

面臨挑戰

  • 線下客流持續萎縮，近5年營收累計下跌超過40%。
  • 品牌形象老化，難以吸引年輕消費者。
  • 內部團隊對數位化轉型缺乏認知與執行能力。
  • 需要在不關閉現有門店的前提下進行轉型。

成果

轉型後18個月內，銷售額從零增長至佔總營收的45%，整體營收回升22%，成功吸引30歲以下消費者佔比從8%提升至35%。品牌更獲網民稱為「打卡聖地」。
